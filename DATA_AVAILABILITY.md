# Data availability

This GitHub repository contains the source code, reproducibility workflows,
derived CSV data, retained numerical checkpoints, verification products, and
plotting/post-processing code supporting the study.

Public repository:

https://github.com/FrancisRVillatoro/nyquist-compacton-shedding

The software release is archived as a versioned Zenodo software record via the
GitHub integration. Source code is licensed under MIT; derived research data
and workflow-generated figures contained in the repository are licensed under
CC BY 4.0.

The two historical MATLAB simulations are deposited separately as a companion
Zenodo dataset under CC BY 4.0. Their immutable names, byte sizes, and SHA-256
hashes are recorded in `metadata/RAW_DATA_MANIFEST.csv`. The software and raw
data Zenodo records should be cross-linked using their Related identifiers.

No external network data are required for the numerical results once the two
raw historical simulations have been obtained.
